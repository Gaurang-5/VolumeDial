# Volume Dial 1.1.0 — first public beta

A small macOS menu bar app with a sculpted volume dial, light and dark finishes, and the current audio output beneath the dial.

## Download and install

Download **Volume-Dial-1.1.0-beta.1-Apple-Silicon.zip** from this release's Assets section. Extract it, move **Volume Dial.app** into **Applications**, and open it. The app appears in the menu bar, without a Dock icon.

Requires an **Apple Silicon (M-series) Mac with macOS 14 or later**. Intel Macs are not supported. The source-code archives GitHub generates are for developers; use the app ZIP to install.

This beta is **ad-hoc signed and not Apple-notarized**. macOS may block it on first launch. See [Apple's instructions for opening apps from an unidentified developer](https://support.apple.com/en-us/102445) and proceed only if you trust the source. Developer ID signing and notarization are planned before a general release.

## Included

- Scroll or drag the dial to change volume; supported trackpads provide haptic feedback.
- Click the sun/moon button in the top-right to toggle light and dark mode. System appearance is available in the right-click menu.
- Click the output name to choose another audio output.
- Adjust supported members of Audio MIDI Setup multi-output groups together.
- Control supported external-monitor audio through DDC/CI using each monitor's reported volume range.
- Right-click for mute, launch at login, and other settings.

## Fixes in this build

- Invalid monitor replies no longer become false zero-volume readings that pull the dial down.
- The menu bar icon toggles the panel closed on a second click.
- Output changes invalidate old volume gestures and wait for in-flight monitor commands.
- Both the app and monitor helper target arm64 and macOS 14.

## Compatibility and limitations

Built-in speakers, headphones, and other devices need writable Core Audio volume controls. Monitor audio needs writable Core Audio volume or DDC/CI volume support through the complete cable/adapter/port path. Some docks, DisplayLink connections, TVs, and proprietary monitor protocols cannot be controlled. The app does not install a virtual audio driver.

Ambiguous display names are intentionally left unmatched to avoid controlling the wrong monitor. A partially supported group adjusts only its controllable members.

Hardware testing covers the available Apple Silicon Mac with BenQ EW2790U and MacBook Pro Speakers, including their multi-output group. Other Mac models, supported macOS versions, monitors, and adapters have not all been hardware-tested. The macOS 14 minimum is checked in both binaries; it is not a claim of testing on every supported OS.
